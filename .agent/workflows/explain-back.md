description: Teach me a file so I can explain it to judges, then quiz me
---
Ask me which file to study (or use the file I name). Then:
1. Explain it in plain English in under 200 words, as if to a smart classmate. Use one small example with real values from this project.
2. Show the three most important lines and what breaks if each is removed.
3. Ask me 5 short questions one at a time, in the style judges use ("why this and not that?", "what happens if...?"). Wait for my answer each time. Correct me kindly.
4. At the end list the points I got wrong and give me one sentence to memorise for each.
Use docs/QA.md for the likely judge questions. Do not edit any code.
