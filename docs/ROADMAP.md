# Roadmap (not in the Round 1 prototype)
1. **P1 Bangla OCR** (Tesseract `ben`) to digitize old khatians, linked to the plot ID, with officer verification.
2. **GIS layer**: mouza maps and boundary overlap detection (India/Rwanda style).
3. **Survey generation linking**: holder-to-holder inheritance chain across CS → SA → RS → BS.
4. **Integration**: API gateway to existing e-registration / e-mutation systems; Estonia-style data exchange between offices.
5. **Witness nodes**: several offices (and a court) co-sign the daily anchor; anchor published on a public page and in print.
6. **Hardware keys** per sub-registrar; key rotation and revocation.
7. **Offline-friendly access**: SMS/USSD plot check for people without smartphones; union digital centers.
8. **PostgreSQL + FastAPI** behind the same service layer; load testing; audit dashboards.
9. **GPS evidence** from the field for disputed boundaries (Zambia-style mobile mapping).
